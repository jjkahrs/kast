Map Bake

The world server's offline navmesh baker and map linter (services/world/tools/mapbake/). The server loads its output as described in World Server, Navmesh.

Baking: kast_mapbake <mapDir> [--out <dir>] (built with the server, on Windows and in the image) bakes one Recast tile per declared tile into <mapDir>/.server/nav/<tx>_<tz>.navtile (or --out). Run it after editing a map's heights, then commit the navtiles; the editor's Play and the server need no tool.

build/debug/kast_mapbake.exe ../../tests/project/maps/hills
# 0_0.navtile: 40 polys, 27452 bytes, 0.97 s   (debug build; one line per tile)
# 4 navtile(s) -> ../../tests/project/maps/hills/.server/nav
docker compose run --rm -T --entrypoint ./kast_mapbake bot /app/maps/hills --out /tmp/nav   # in the image
  • Input: each tile's ground triangles (map::for_each_triangle, the triangles the client renders and Jolt collides with) plus a border from its neighbours on the map, so paths cross tile edges. A tile without heights is flat.
  • Zone objects: every obstacle and interactable in objects/<tx>_<tz>.json (the tile's and its neighbours', for the border) is cut out of the walkable area by its shape: a box's footprint turned by its yaw (rcMarkConvexPolyArea) or a cylinder (rcMarkCylinderArea), the whole column under it. The cut happens before the agentRadius erosion, so agents keep that clearance round every object. Visuals are ignored (World Server, Maps, Objects). Re-bake after moving a blocking object.
  • Params: the manifest's nav (defaults agentRadius 0.4, agentHeight 1.8, maxClimb 0.5, maxSlopeDeg 45, cellSize 0.5; cell height is cellSize / 2). maxSlopeDeg is also the client's character max slope on terrain, so the bake and Jolt agree on what is walkable. cellSize must divide 256, and tan(maxSlopeDeg) * cellSize should not exceed maxClimb, or walkable slopes come apart.
  • Lint first: height seams (a tile's edge samples must equal its neighbour's), every spawn file (map::parse_spawns, tile on the map, ids unique), every objects file (map::parse_objects: a bad file, an unknown type, a blocking object without a shape or any other bad entry, tile on the map, interactable ids unique) and every .server/interactables file (map::parse_interactables, as the server loads them). Any error is printed (seam 0_0 | 1_0: 257 samples differ, worst 1.53 m at z 0) and the tool exits 1 having written nothing. Usage errors exit 2.
  • Cost: with cellSize 0.5, about 1 s and 30-45 KB per hills tile (40-90 polygons).
