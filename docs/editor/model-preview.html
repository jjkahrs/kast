Model Preview

The Model Preview panel shows one model file and its animation clips without placing it in a scene. Double-click a .glb, .gltf, .fbx or .obj file in the Assets panel to open it. The panel opens as a tab beside Scene (it is a normal dockable window) and comes to the front; double-clicking another model shows that one instead. There is one Model Preview: close it with its tab's x.

The view

  • The model renders with its own materials (embedded in the file, as a ModelRenderer without material overrides draws it) under a directional light, ambient light and a procedural sky, the same lighting as the Shader Preview. No shadows, grid or skeleton.
  • On opening, the camera frames the model's bind-pose bounds. Drag the image with the left mouse button to orbit, turn the wheel to dolly in and out. Reset view frames the model again from the starting angle.

Animation

A model with clips plays its default clip (Idle, else Idle_A, else the first containing "idle", else the first; see Models and animation), looping at speed 1. The combo lists every clip: picking one starts it from the beginning. Pause freezes the pose; Play resumes it. A model without clips shows No animations instead of these controls.

Stats

Above the image: Meshes (submeshes, one per material slot), Vertices, Triangles, Nodes (the node hierarchy), Bones (distinct joint nodes across the skinned meshes), Clips and the bind-pose bounds Size in meters (x by y by z).

LOD

The collapsible LOD section shows and edits the model's LOD import settings (its <model>.import.json):

  • Auto LOD (generate levels), Levels (1 to 8) and Cull below last.
  • A table with a row per level: a radio button to preview that level in the view (the default is LOD0), its target ratio of LOD0's triangles, its screen height threshold in percent, and the triangles the imported model has at that level (with the percentage of LOD0's), so a level that missed its target shows.
  • Apply writes the sidecar and the model is imported again (the new counts show within a frame); Revert drops unapplied edits.

Authored levels (_LOD0, _LOD1 ... nodes) show with their own triangle counts. --preview-lod <n> starts on level n.

Files

  • A file that can't be loaded (missing pieces, corrupt, unsupported) shows Can't load this model in the panel; the Console has the importer's error. The editor keeps running.
  • Saving the file on disk (for example from Blender) shows the new version within a frame. The selected clip stays selected if the new file still has a clip of that name, else the default clip plays.
  • Renaming or moving the file (or a folder holding it) in the Assets panel keeps the preview on it. Deleting it clears the panel: it says The file doesn't exist. (as for a --preview-model path that isn't there).

Command line

For screenshots and tests, with --project: --preview-model <path> opens the panel on that project-relative model at startup, and --preview-clip <name> plays that clip instead of the default (a name the model doesn't have logs a warning and plays the default). See Command line. Example: kast_editor --project tests/project --preview-model models/female-128-anim.glb --preview-clip Angry --frames 120 --screenshot preview.png
