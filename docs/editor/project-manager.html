Project Manager

Running kast_editor.exe with no project or scene (or with --launcher) opens the Kast Project Manager window (1024×600, resizable) instead of the editor. Opening or creating a project there starts a new kast_editor.exe --project <dir> process (SDL_CreateProcess, sharing the console) and closes the Project Manager's window. Its process then waits for that editor and exits with the editor's exit code, so a terminal (run.bat) stays attached until the editor closes and its log stays in the terminal. Closing the Project Manager without choosing exits 0 and starts nothing.

  • List (left), most recently opened first: the project name, its folder and when it was last opened. Click selects; double-click, Enter or Open opens the selected project. A project whose folder is missing or whose project.kast is missing or invalid (checked when the window opens) is greyed out with the reason, and can't be opened (Open's tooltip says why); it stays listed until removed.
  • New Project: a modal with Name, Directory (type a parent directory or pick one with Browse...; cancelling the picker keeps the field) and a Will create: <directory>\<folder> preview. The folder name is the name trimmed, with ASCII letters lower-cased and each run of whitespace replaced by - (" My Game " → my-game); non-ASCII characters are kept. Create is disabled, with a one-line reason, if that folder name is empty, ./.., ends with . or contains < > : " / \ | ? * or a control character, if the directory is empty, missing or not a directory (parent directories are never created), or if <directory>\<folder> already exists. Create makes that one folder, writes scenes/main.scene in it (the editor's default scene: light, ground, cube, Main Camera and the editor camera framing them) and project.kast ("name" = the trimmed typed name, "startScene": "scenes/main.scene"), adds it to the list and opens it, so the editor starts in main. A failure shows under the list and removes the folder if this attempt made it. Cancel or Esc writes nothing.
  • Import: pick a project.kast (the dialog filters *.kast; other file names are rejected). An invalid file shows the error under the list and changes nothing. Otherwise the project is added to the top of the list (an already listed folder just moves there, never twice) and opened.
  • Remove: drops the selected entry from the list. Files on disk are never touched; no confirmation.
  • If the editor can't be started, the error shows under the list (and in the log) and the Project Manager stays open; the list keeps the update.

Recent-projects list: %APPDATA%\Kast\Editor\projects.json (SDL_GetPrefPath("Kast", "Editor")), or --projects-file <path>. A JSON array, most recent first, 2-space indent:

[
  {
    "path": "C:/dev/games/my-game",
    "name": "My Game",
    "lastOpened": 1791900000
  }
]

path is the absolute, normalized project folder (/ separators; compared case-insensitively, so a folder is listed once), name the project name when last opened, lastOpened Unix seconds. Every successful open adds or moves the project to the top: Open/double-click/Enter, Import, New Project, --launcher-open, and the editor's own --project startup once its window opens (not --build / --save-scene). An unreadable or invalid file is copied to projects.json.bad, a warning is logged, and the list starts empty.
