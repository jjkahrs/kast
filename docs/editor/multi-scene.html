Multi-scene editing

The editor can have several scenes open at once, each saving to its own .scene file, and runs them together in Play: the editor side of additive scenes. One open scene is active: its sky, lighting, post-processing and physics settings are the ones in effect (and edited in Window > Lighting, Post Processing and Physics and the Systems panel), new objects go into it, and the window title names it.

The Hierarchy

  • With one scene open the Hierarchy is the plain entity tree. With more, each open scene is a collapsible header with its entities under it: the scene's name, * while it has unsaved changes, and (Active) on the active one, whose header is drawn in the highlight color (#ffcc00) instead of the header color (#ffaa00). Hovering a header shows its file.
  • Drag an entity onto another scene's header to move it into that scene as a root, or onto an entity of another scene to parent it there: either way its whole subtree moves into that scene (cross-scene references are not kept). The move is one undo step and leaves both scenes with unsaved changes.
  • Right-click a header for:
    • Set Active Scene: makes it active (not an undo step).
    • Save Scene: saves just that scene (an untitled one asks for a file).
    • Remove Scene: closes it, asking first to save it if it has unsaved changes (Save / Don't Save / Cancel). The only open scene can't be removed; removing the active one makes the first remaining scene active.
    • New Scene: adds an empty, untitled scene to the open set.
    • Open Scene Additive... and Create (an object as a root of that scene).
  • Right-clicking the empty space below the scenes creates objects in the active scene. In prefab edit mode the Hierarchy shows just the prefab, as before.

File menu and saving

  • File > Open Scene Additive... adds a scene to the open set (it isn't active and has no unsaved changes). A scene that is already open is refused, and so is one from another project.
  • File > New Scene Additive adds an empty, untitled scene to the open set.
  • File > Open... and New replace the whole open set, as before.
  • Ctrl+S / File > Save saves every open scene with unsaved changes, each to its own file (an untitled one asks where), and always the active one. The unsaved-changes prompt (New, Open, Quit, Build) saves them the same way.
  • Each scene saves only its own entities and settings, in the usual deterministic format: a scene opened alongside others and saved unchanged is byte-identical to its file. The editor camera is saved into the active scene.
  • Adding or removing a scene from the open set and Set Active Scene are not undo steps.

Undo and unsaved changes

All open scenes share one undo history (Undo and redo). Each step records which scenes it touched, so each scene's * follows its own save point: undoing an edit of scene B back to where B was saved clears B's * whatever happened to the others.

Play

  • Play runs every open scene: their systems (each script once), entities and physics together, with the active scene's settings.
  • While playing, Lua can load and unload scenes (kast.loadScene(path, {additive = true}), kast.unloadScene) and change the active one; the Hierarchy shows the scenes as they are, and the title names the running active scene when it isn't the edited one.
  • Stop restores the open set exactly as it was: the scenes (also ones Lua unloaded or added), the active scene, their unsaved-changes markers and the selection.

Prefab edit mode

Opening a prefab puts the whole open set aside; going Back brings every scene back with its active scene, unsaved changes and undo history.

Reopening the set

The editor remembers each project's open scenes and its active one in the editor settings (editor_settings.json, "openScenes", keyed by the project folder; untitled scenes are left out) and reopens them the next time it opens that project (--project or the Project Manager). A remembered scene whose file is gone is skipped with a warning in the Console. Opening a scene by --scene opens just that scene.

Command line

For tests and screenshots (Command line): --open-additive file (repeatable) opens scenes additively after --scene; --active-scene N makes open scene N (0 = the first) active; --move-to-scene ID,N moves entity ID (its in-memory id: file id plus the scene's slot times 4294967296) into open scene N as a Hierarchy drop does; --scene-menu N opens scene header N's menu and --remove-scene N its Remove Scene.
