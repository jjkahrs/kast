Tests

ctest --preset debug (or release, relwithdebinfo) runs the tests below. Many open a window; they stay off the main monitor: every test runs with KAST_WINDOW_POS=secondary, which opens windows on the first display that isn't the primary one (with only one display they open on it, with a warning). Configure with -DKAST_TEST_WINDOW_POS=X,Y (e.g. cmake --preset debug -DKAST_TEST_WINDOW_POS=-1900,40) to pin them to a desktop position instead.

Image checks

Screenshot tests read and compare PNGs with kast_self_check:

  • kast_self_check --probe-png <png> <fx,fy,r,g,b,tolerance>...: each pixel at (fx, fy) (0..1 across and down the image) is within tolerance of r, g, b (0..255) per channel. Prints each probe's color; fails if any is off.
  • kast_self_check --diff-png <a.png> <b.png> <maxMeanAbsDiff> [x,y,w,h[,bx,by]]: the mean absolute difference per RGB channel (0..255) over every pixel of two same-sized images is at most maxMeanAbsDiff (the shader tests use 0.00392, 1/255). Prints diff ok: mean 0.000000 (limit 0.003920), max 0 over 1600x900 (or diff FAIL: ...), the mean and the largest single difference, and exits 1 above the limit. With a rect, only the w x h pixels at x, y (window pixels from the top left) are compared, e.g. one object's crop; with bx,by b's rect starts there instead, so an editor shot's Game view can be compared with a player screenshot of the view's size (322,44,955,583,1,0). A test that wants images to differ passes on diff FAIL: mean.
