Kast Engine

engine/ is the reusable runtime (SDL3 window + bgfx Direct3D 11, EnTT scene, renderer, scene files) that the editor, the built game client (kast_player) and the tools are built on. These pages cover the scene conventions and every engine feature, including the kast.* Lua API.
