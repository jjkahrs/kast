Zones

A map (maps/<folder>/) is made of 256 m tiles; a zone is a named set of its tiles that is contiguous (connected through shared edges). Every declared tile is in exactly one zone. Moving from one zone into the next is seamless: the same map, the same scenes around you, no loading screen and no transfer; only the zone's own scene streams in and out and Lua hears about the change. Zones are client-side: the world server ignores them.

zones.json

Optional, maps/<folder>/zones.json:

{ "version": 1, "zones": [
  {"id": "west", "name": "West Vale", "tiles": [[0, 0, 1, 2]], "flags": {"pvp": false}},
  {"id": "east", "name": "East March", "tiles": [[2, 0, 2, 2]], "flags": {"pvp": true}}
]}

id (required, unique; letters, digits, _, -), name (defaults to id), tiles (inclusive rectangles like map.json's) and flags (any JSON object, handed to Lua untouched). Without the file the map is one implicit zone: id = the map folder, name = the map's name, every tile. The full rules and checks are in World Server, Maps, Zones (services/world/map/zones.h); zones are authored in the editor's Map tab. In Play, a zones.json that fails its checks logs one Console error (Terrain: maps/<folder>/zones.json: ...; the map is one zone) and the map plays as its implicit zone. kast_player builds ship zones.json and zones/*.scene in game.pak like the rest of the map folder.

Zone scenes

Each zone can have its own scene, maps/<folder>/zones/<zoneId>.scene (world coordinates, additive, never the active scene; pure logic in engine/zone_scenes.h). In editor Play and kast_player zone scenes stream with the tile scenes, in the same plan (planTileScenes) and with the same rules:

  • a zone's scene is wanted while any of its tiles is within Terrain.radius of the streaming centre (the NetworkLocalPlayer, else the active camera): the zone's tiles among tiles_around;
  • a loaded zone scene that is not wanted unloads (except the active scene); at most one scene loads a frame, tile scenes first, then zone scenes in zones.json order;
  • each load or unload publishes map.zoneScene.loaded / map.zoneScene.unloaded with {map, zone, path} (e.g. {map = 7, zone = "west", path = "maps/tilegrid/zones/west.scene"});
  • a broken file logs one error (Map: zone scene '...' did not load: ...) and is skipped for the session; a scene file whose name is no zone's id never loads;
  • in the editor, Stop restores the scenes you had open.

Zone events

Terrain streaming (publisher kast.terrain, Events) tracks the zone of the streaming centre each frame. When it changes it publishes zone.left {map, zone} for the old zone, then zone.entered {map, zone, name, flags} for the new one. When Play (or a map) starts, zone.entered comes alone; stepping off the map's tiles gives zone.left alone. Only the local focus has zone events (no NPC or remote player events, no server messages).

Lua

FunctionReturnsDescription
kast.map.zone() table or nil {id, name, flags} of the zone the streaming centre was in at this frame's terrain update; nil with no Terrain map or off its tiles.
kast.map.zoneAt(x, z) table or nil The same for the world point (x, z) on the current Terrain map; nil off its tiles. Raises if x or z is not a finite number. 
kast.subscribe("zone.entered", function(e)
    kast.log("Entering " .. e.name .. (e.flags.pvp and " (PvP)" or ""))
end)
