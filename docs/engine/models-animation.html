Models & Animation

Model files placed anywhere in the project render through a ModelRenderer; skinned characters play skeletal animation clips through an Animator. The editor imports each model file with Assimp once, into a binary .kmodel it caches (see Import cache); Build cooks every model into game.pak as .kmodel, and the built game reads only those (it has no Assimp).

  • Formats: glTF 2.0 (.gltf with its .bin and images, or .glb), FBX (.fbx) and OBJ (.obj with its .mtl). Sidecar files (.bin, .mtl, images) resolve next to the model.
  • Units and axes: everything is normalized to meters and Y-up on load. glTF is meters / Y-up; OBJ has no unit and is taken as meters; FBX is converted from its UnitScaleFactor (centimeters per unit) and its up / front / coord axis metadata (e.g. Z-up files are turned Y-up). The same 1 m cube lines up as OBJ and glTF. Entity Transform.scale is the only user scale. (The sample Kenney FBX character is authored 3.76 m tall; models.scene scales it by 0.5.)
  • What loads: meshes (one submesh per material slot; positions, normals, UV0, up to 4 joint weights per vertex, renormalized), the node hierarchy, skins (bind poses), animation clips (name, duration, per-node translation / rotation / scale keys) and embedded materials mapped onto .mat fields: base color factor and texture, metallic, roughness, metallic-roughness texture, emissive, alpha mode and cutoff (OBJ Kd / d), and from glTF the normal texture and scale, occlusion texture and strength, emissive texture, doubleSided (cull mode none, else back) and KHR_materials_unlit (see Materials). Tangents are generated for normal mapping (Shaders). Embedded GLB images decode like other textures (PNG/JPG). A mesh on a node without a skin renders at that node's transform.
  • Caching: each model loads once per project-relative path and is shared by every entity using it; a changed file or sidecar (.bin, .mtl) reloads within a frame (modification time, as .mat files; not in the built game).
  • Import cache (editor): a model is imported once and kept as <project>/.kast/model_cache/<key>.kmodel (a dot-folder: never shipped; safe to delete). The key is a hash of the model's project-relative path, its bytes, the bytes of every sidecar it imports from (a .gltf's or .glb's external buffers, an .obj's mtllib files), the .kmodel format version and the importer version (the Assimp version, its import flags and the importer's own revision). So an unchanged model loads from the cache on the next start (Loaded model 'models/hero.glb' (cache hit)) without running Assimp, while editing the file or a sidecar, upgrading Assimp or a new .kmodel version imports it again (Loaded model 'models/hero.glb' (imported in 0.24 s)). The cache is never pruned. .kmodel is a versioned little-endian binary of everything the engine keeps of a model (meshes with their vertices and indices, nodes, skins and inverse binds, clips, materials, embedded image bytes, bounds); its byte layout is documented in engine/model.h.

  • ModelRenderer: model (project-relative .glb/.gltf/.fbx/.obj; empty = renders nothing) and materials, the per-slot .mat overrides by slot index: a JSON array of strings, "" (or no entry) = the model's embedded material. castShadows / receiveShadows [true] as for MeshRenderer (skinned meshes cast their animated pose). It is the first built-in field that is a list (std::vector<std::string>); it saves, loads, duplicates and goes through kast.get / kast.set like any other field. No scene version change.

    "ModelRenderer": { "model": "models/female-128-anim.glb", "materials": ["materials/gold_r05.mat"] },
"Animator": { "clip": "Idle_A", "loop": true, "speed": 1, "playOnStart": true }

  • Animator: clip (a clip name of the model; empty = bind pose), loop [true], speed [1, 0–10; values outside are rejected] and playOnStart [true]. It drives the ModelRenderer on the same entity: without one it does nothing (the Inspector says so, kast.*Animation* raise). Keys are sampled with lerp (translation, scale) and slerp (rotation), looping wraps and not looping holds the last frame (then playing turns false). Switching clips crossfades from the current pose over the fade time. Root-motion clips (*_RM) play in place: the root bone moves as authored, the entity Transform never moves. Playback state (clip, time, fade, pose) is runtime-only: never saved, reset by Stop.

  • GPU skinning: vs_mesh_skinned.sc (same PBR fragment shader, lights, alpha modes and fog), 4 weights per vertex, bone matrices in a uniform array of at most 128 bones per skinned mesh. A model over the limit logs one error and renders that mesh in bind pose, unskinned.
  • Edit mode: Animators preview in the Scene view: a playOnStart clip plays; otherwise the clip's first frame shows, paused. The Animator Inspector has a Clip dropdown (the model's clips) and a Preview row: Play / Pause and a time scrub (dragging pauses). The preview never saves and never marks the scene dirty; Play mode starts every playOnStart clip from 0.
  • Editor: drag a model from the Assets panel onto the Scene view (an entity at the origin) or the Hierarchy (at the root, or onto an entity for a child): the entity is named after the file and gets a ModelRenderer, plus an Animator if the model has clips, playing Idle if there is one, else Idle_A, else the first clip whose name contains "idle" (any case), else the first clip. GameObject > Model (and the Hierarchy's right-click menu) adds an empty ModelRenderer. Its Inspector has a Model combo (the project's model files) and a .mat combo per material slot, named as in the file, with None (embedded). Scene view picking and focus use the model's bind-pose bounds. Renaming or moving a model, a .mat or a folder holding them in Assets rewrites the open scene's ModelRenderer.model and override paths.

  • Lua:

    Function Does
    kast.playAnimation(id, clip, opts) Plays clip; optional opts = {loop =, speed =, fade = seconds} (fade crossfades from the current pose, default 0). Writes the Animator's clip, loop, speed.
    kast.stopAnimation(id) Stops at the current pose.
    kast.getAnimationState(id) {clip = name, time = seconds into the clip, playing = bool}.
    kast.getAnimationClips(id) The model's clip names, in file order.

    kast.get / kast.set work on Animator fields (a clip change starts that clip). An invalid entity, an entity without Animator + ModelRenderer, a model that didn't load, an unknown clip, or a speed / fade out of range raise a Lua error naming the problem.

  • Fallbacks (the scene always loads): a missing, corrupt or unsupported model renders a magenta cube at the entity and warns once per path; an unknown Animator.clip (from the scene or the Inspector) shows the bind pose and warns once; over 128 bones, see above.

  • Built game: Build cooks every model file in the project into game.pak as <path>.kmodel (e.g. models/hero.glb.kmodel) in place of the model file and its .bin / .mtl sidecars (see Build). Scenes, prefabs and Lua keep naming models/hero.glb: the player maps that path to its cooked entry (Loaded model 'models/hero.glb' (cooked)) and renders and animates it the same way. The player has no Assimp. A model with no cooked entry (e.g. a path no project file has) logs one error, Model 'models/x.glb': game.pak has no cooked model for it ..., and renders a magenta cube.
  • Limits: 128 bones per skinned mesh, 4 weights per vertex, one UV set; no morph targets, no node (non-skinned) animation playback, no animation layers / blend trees / events / IK, no root-motion extraction, no LOD or instancing, embedded images only as PNG/JPG. Animations stored in separate animation-only files (e.g. Kenney's run.fbx) are not merged into a model. Assimp 6.0.4 crashes on a glTF skin without inverseBindMatrices (valid glTF); such files must include them.
  • Samples (tests/project/): models.scene (OBJ cube, glTF cube, the GLB character, Kenney's CC0 FBX character with a .mat skin override, next to primitives), models_anim.scene (Cheering_Two_Hands on start), models_material.scene (slot 0 overridden with gold), models_missing.scene (missing model), models_lua.scene (scripts/animation_test.lua), with models/ (models/kenney/License.txt: CC0).
