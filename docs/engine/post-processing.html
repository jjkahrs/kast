Post-processing and fog

Each scene can opt into an HDR post-processing stack and distance fog, set per scene ("postProcessing" in the scene file) and edited in Window > Post Processing (hidden by default; a section per effect with its Enabled box; edits show live and mark the scene dirty). Every effect is off by default, so a scene without settings renders as it always did. The Scene view, the Game view and the built game all apply it.

  • Pipeline: meshes render linear HDR color into an RGBA16F target (plus depth); engine/post_process.h then runs, in order: bloom, exposure, tonemap, color grading, vignette, sRGB encode, FXAA, into the view's image (the backbuffer in the player). With the screen-space effects below on, the opaque scene first gets SSAO, SSR and volumetric fog composited, then the blended draws, then depth of field, before bloom. Overlays (grid, axes, camera frustums, light range) and gizmos draw after it, depth-tested against the scene, and are never post-processed; game GUIs draw over the final image and are never post-processed.
  • Screen-space and volumetric effects, each with its own page and its own section in the panel: SSAO ("ssao": ground-truth ambient occlusion of the indirect diffuse light), screen-space reflections ("ssr": replace probe / IBL specular where rays hit), depth of field ("depthOfField": thin-lens bokeh, manual focus) and volumetric fog ("volumetricFog": lit, shadowed froxel fog with FogVolume regions). Lua: kast.ssao, kast.ssr, kast.dof, kast.volumetricFog (get() / set{...}). As for every "postProcessing" block, an invalid value fails the scene's load (the open scene is left untouched).
  • Tonemapping: exposure in EV (-10..10, color times 2^EV) and operator None (clamp to 0–1, the look without post) or ACES (Narkowicz's filmic fit, x(2.51x + 0.03) / (x(2.43x + 0.59) + 0.14): bright lights and emissive surfaces roll off instead of clipping to flat white).
  • Bloom: a soft-knee bright pass on HDR luminance above threshold [1] at half resolution, blurred down 5 levels (to 1/32) and back up, each level mixing in the blurred level below by the radius [0.5] scatter; added back times intensity [0.5]. Raise a material's emissive intensity above the threshold to make it glow.
  • Color grading (after the tonemap): contrast [1, 0–2] (power curve around mid grey 0.18), saturation [1, 0–2], colorFilter [white, linear RGB tint] and temperature [0, -1 cool .. 1 warm white balance].
  • Vignette: intensity [0.3, 0–1] darkens toward the corners over the outer smoothness [0.5, 0.01–1].
  • FXAA: on/off, on the final sRGB image (the FXAA 3.11 console variant).
  • Fog (shaded per mesh in fs_mesh.sc, not a post pass, so blended meshes fog by their own distance): exponential-squared, 1 - exp(-(density * max(distance - start, 0))^2) toward color (linear RGB) [density 0.05, start 0 m]. While fog is on, the views clear to the fog color so distant meshes fade into the background.
  • Scene view: the toolbar's Post box shows the scene with or without the post effects, including SSAO, SSR, depth of field and volumetric fog (on by default; the distance fog always shows). --no-scene-post starts with it off.
  • Blended meshes now blend in linear space (before the sRGB encode), which is physically correct but looks slightly different from the gamma-space blending before post-processing.
