Materials

Meshes render with PBR metallic-roughness materials (glTF semantics) defined in .mat files: JSON, any folder of the project, referenced by MeshRenderer.material (project-relative). Every field but version is optional (default in brackets); unknown keys and invalid values make the file invalid.

{
  "version": 1,
  "baseColor": [0.8, 0.8, 0.8, 1],
  "baseColorTexture": "textures/checker.png",
  "metallic": 0,
  "roughness": 0.5,
  "metallicRoughnessTexture": "",
  "emissiveEnabled": false,
  "emissive": [0, 0, 0],
  "emissiveIntensity": 1,
  "alphaMode": "opaque",
  "alphaCutoff": 0.5
}
  • baseColor linear RGBA 0–1 [0.8 grey, alpha 1], times baseColorTexture (sRGB; project-relative, empty = none).
  • metallic, roughness 0–1 [0, 0.5], times metallicRoughnessTexture (linear, glTF packing: G = roughness, B = metallic).
  • emissiveEnabled [false]: when on, emissive (linear RGB 0–1 [black]) times emissiveIntensity (≥ 0 [1]) is added after lighting (shows without lights); an intensity that lifts it above the bloom threshold glows. Older files with only emissive load with emission on if it is non-black, and channels above 1 move into the intensity.
  • alphaMode [opaque]: mask discards pixels whose alpha is below alphaCutoff [0.5]; blend draws after every opaque mesh, far to near by the mesh's world-space center (no per-triangle sorting), alpha-blended, depth-tested but not depth-written.
  • Shading: Cook-Torrance (GGX distribution, Smith / Schlick-GGX geometry, Schlick Fresnel, F0 = mix(0.04, baseColor, metallic)) for the first DirectionalLight and up to 8 PointLights per mesh; ambient adds a diffuse term and a flat specular term (roughness-aware Fresnel), so metals are not black with ambient light only. Direct light is scaled by the shadow maps (the directional term by its cascade, each shadowed point light by its cube) unless the mesh's receiveShadows is off. No image-based lighting. The shader outputs linear HDR color (formulas in engine/shaders/fs_mesh.sc); the post chain tonemaps and encodes it to sRGB.
  • Textures: PNG and JPG (stb_image), mipmapped at load (sRGB-correct filtering for base color), shared by path.
  • Fallbacks (the scene always loads): a missing or invalid .mat renders unlit magenta; a missing or undecodable texture renders as white. Each is logged once per path, with the reason.
  • Editor: Assets > Create > Material writes new_material.mat (default material) into the folder and starts a rename. Selecting a .mat in Assets shows it in the Inspector (until an entity is selected): color pickers, sliders (clamped), the alpha mode and texture combos (the project's .png / .jpg); every edit saves the file and the views show it the same frame. The MeshRenderer Inspector picks a material from the project's .mat files or None (default). Renaming or moving a .mat or texture (or a folder holding them) in Assets rewrites the open scene's MeshRenderer.material paths and the texture paths inside every valid .mat; deleting one leaves the references to fall back. .mat and texture files changed on disk (e.g. in an external editor; double-click opens a .mat there) reload within a frame: the renderer checks each loaded file's modification time every frame (not in the built game).
  • Lua (Play): kast.set(e, "MeshRenderer", {material = "materials/red.mat"}) swaps the material. kast.setMaterialProperty(id, name, value) changes one field for that entity only: the first call copies its material into a per-entity instance (Unity's renderer.material); other entities using the same .mat are unaffected. kast.getMaterialProperty(id, name) reads the instance, else the .mat. Values are checked like .mat fields (invalid raises); colors are {r, g, b[, a]} or {x =, y =, z =[, w =]} and come back as arrays. Instances are never saved: Stop discards them, and kast.set to another material drops the entity's instance.
  • Built game: .mat and texture files ship in game.pak like every other project file; the player renders them the same way.
  • Sample: tests/project/materials.scene (gold and red plastic spheres at roughness 0.1 / 0.5 / 0.9, PNG and JPG textured cubes, a metallic-roughness textured sphere, an emissive sphere, a mask cutout, two overlapping blended planes, a broken and a missing .mat, a missing texture) with its materials/*.mat and textures/*.
