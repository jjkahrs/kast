Audio

2D (non-spatial) sound on miniaudio (engine/audio.h). Editor Play and kast_player both run it; in Edit mode only the Inspector's Preview makes sound.

Formats: .wav and .mp3 only (extension matched ignoring case); any other extension is an error. Every file is read through kast::readFile, so a built game plays its clips from game.pak.

AudioSource component (Add Component, Inspector, scene file):

Field Meaning [default]
clip project-relative .wav / .mp3; empty = none [""]
bus Master / Music / SFX / UI / Voice [SFX]
volume 0..1 [1]
loop repeat until stopped [false]
playOnStart start the clip when Play starts and when a scene loads during Play [false]

A volume outside 0..1 or a clip with another extension is rejected (scene load, Inspector edits). A missing or corrupt clip shows its error in red under the Inspector's clip picker, logs one error at Play (AudioSource on '<entity>': ...), plays nothing, and Play goes on.

Buses: a fixed set, Master, Music, SFX, UI, Voice; every sound plays on exactly one (default SFX). Music, SFX, UI and Voice feed Master. Gain = sound volume x bus volume x Master volume; a muted bus (or muted Master) is silent. Volumes are 0..1.

Voices: at most 32 sounds at once. A play when all 32 are busy stops the oldest non-looping voice and reuses it (its handle goes stale). Looping voices are never stolen: if all 32 loop, the new sound is dropped with a warning (Sound '<clip>' dropped: all 32 voices are looping) and play returns 0 (a stale handle). A non-looping voice frees itself when its clip ends; a looping one repeats seamlessly until stopped.

Loading: clips on the Music bus are decoded while they play (streamed from the file's bytes, one decoder per voice). All other clips are decoded once, converted to the output format, and cached by project-relative path; the cache is dropped at each Play start, so edited files are picked up.

Lifecycle: Play start stops every voice, sets the buses to the project defaults (below) and starts the playOnStart sources (before the Lua inits). Pause holds every voice where it is; resume continues them from that position. Stop stops and frees every voice. A kast.loadScene switch stops every voice, then the new scene's playOnStart sources start; runtime bus levels carry over the switch. Music does not continue across a switch.

kast.audio (bus names are the strings above; errors raise at the calling line, like kast.*):

Function
play(path, opts?) -> handle opts = {bus = "SFX", volume = 1, loop = false}, every key optional; returns 0 if dropped
stop(h), pause(h), resume(h), setVolume(h, v) on one sound
isPlaying(h) -> bool true while the voice lives and is not paused by pause(h)
stopAll(bus?) every sound, or only those on bus
setBusVolume(bus, v), getBusVolume(bus) -> v, setBusMuted(bus, muted) runtime bus levels, not saved
playSource(id) -> handle, stopSource(id) the entity's AudioSource (its clip, bus, volume, loop); stopSource stops the last voice playSource or playOnStart started for it

A handle whose voice ended, was stopped or was stolen is stale: isPlaying returns false and the other calls do nothing (not an error). A missing, unreadable or corrupt file, another extension, an unknown bus or option, a volume outside 0..1, a non-number handle and playSource / stopSource on an entity without an AudioSource raise a Lua error (kast.audio.play: cannot read 'sounds/x.wav'); the system keeps running.

local music, wasDown = nil, false
return {
    init = function()
        music = kast.audio.play("sounds/theme.mp3", {bus = "Music", volume = 0.6, loop = true})
    end,
    update = function(dt)
        local down = kast.input.keyDown("Space")
        if down and not wasDown then
            kast.audio.play("sounds/jump.wav", {volume = 0.8}) -- SFX, one-shot
        end
        wasDown = down
        if kast.input.keyDown("P") then kast.audio.pause(music) else kast.audio.resume(music) end
    end,
    shutdown = function() kast.audio.stopAll("SFX") end,
}

No audio device: if the output device can't be opened, one warning is logged (No audio output device: sound plays on the null backend (silent)) and miniaudio's null backend is used; handles, voices, buses and the cache behave normally. --no-audio-device (editor and kast_player) forces this; the tests use it.

Editor:

  • Inspector AudioSource: a Clip combo of the project's .wav / .mp3 files, then bus, volume, loop and playOnStart. Preview plays the clip in Edit mode at the component's volume and bus (with the project's bus defaults); Stop Preview stops it, and selecting another entity stops it too. Preview is disabled during Play.
  • Assets panel: .wav / .mp3 files have a speaker icon.
  • Window > Mixer: a volume slider and Mute box per bus that edit the project's default levels, saved in project.kast ("audio", see Projects) when a drag ends; during Play edits also apply to the session at once. During Play it also lists the active voices (clip, bus, volume, loop, Playing / Paused) and the count out of 32.

C++: kast::Audio (from LuaSystems::audio()); Audio::Output::Offline has no device and render() pulls the mix, which the self-checks use to measure output. kast::clipInfo reads a clip's native frames, channels and sample rate.

Limits: no 3D / spatial sound (no listener, distance or panning), no effects, pitch or speed, no fades or crossfades, no OGG / FLAC, no custom buses, no voice priorities.

Sample: tests/project/audio.scene (Music loops sounds/wave-demo.wav on the Music bus with playOnStart; Jukebox has a UI-bus AudioSource) runs scripts/audio_sfx.lua, which plays sounds/mp3-demo.mp3 once and then a short tone twice a second, alternating kast.audio.play and kast.audio.playSource.
