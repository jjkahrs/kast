POST /v1/auth/logout none {refreshToken} → 204. Revokes that session
POST /v1/auth/forgot-password none {email} → 202 always. 5/h/IP

Query: q (email substring, or exact id when all digits), role, banned, verified, locked (true/false), limit (1–100, default 50), offset. → {accounts, total, limit, offset}; each account has failedLoginCount, lockedUntil and activeBan. GMs only get player accounts
POST /v1/admin/accounts admin {email, password, role?} → 201. Created already verified; role defaults to player. 409 email_taken
GET /v1/admin/accounts/:id admin, gm Account plus bans (full history, newest first, with liftedAt/liftedBy). GMs: player accounts only

POST /v1/admin/accounts/:id/verify-email admin Mark the email verified → 204
POST /v1/admin/accounts/:id/password-reset admin Send the normal "forgot password" email → 204
POST /v1/admin/accounts/:id/unlock admin Clear failedLoginCount and lockedUntil → 204

Roles

Everything under /v1/admin needs an access token with role admin, except four routes that also accept gm: list accounts, account detail, ban and unban. A GM may use them only on accounts whose role is player; any other target gives 403 forbidden, and the account list only ever returns players to a GM. Access tokens already issued keep working until they expire (at most 15 minutes) after a ban, delete, role change or session revoke.

Errors

Every error has this shape: {"error":{"code":"snake_case","message":"…","details":…}}. details is present only for validation_error (a list of {path,message}), account_banned ({reason,expiresAt}) and account_locked ({lockedUntil}). Responses never include stack traces or SQL.

Status Codes
400 validation_error, invalid_token, cannot_modify_self
401 unauthorized, invalid_credentials, invalid_refresh_token
403 email_not_verified, account_banned, forbidden
404 not_found, account_not_found, realm_not_found
409 realm_name_taken, email_taken
413 payload_too_large (JSON body limit is 10 kB)
423 account_locked
429 rate_limited, with a Retry-After header
500 / 503 internal_error / db_unavailable
