Configuration

Every setting is an environment variable, checked at startup: a bad or missing one stops it with one line per problem. services/chat/.env.example has them all; the compose stack sets them itself (Setup).

VariableDefaultMeaning
CHAT_HOST 0.0.0.0 Address both ports listen on
CHAT_PORT 7778 Game clients
CHAT_LINK_PORT 7779 World servers (internal link); must differ from CHAT_PORT. Keep it off the public network
CHAT_LINK_SECRET (required) Shared with every world server (CHAT_LINK_SECRET there); at least 16 characters. Never logged
CHAT_BIND_TIMEOUT_MS 5000 How long an authenticated client waits for its character's CharOnline before Disconnect{no_character}
MAX_CONNECTIONS 5000 Game client connections; more get server_full
MAX_FRAME_BYTES 4096 Largest frame a client may send
HANDSHAKE_TIMEOUT_MS 10000 TLS + Hello + Auth (plus CHAT_BIND_TIMEOUT_MS for clients)
IDLE_TIMEOUT_MS / PING_INTERVAL_MS 60000 / 20000 Heartbeat, both ports
MSG_RATE_PER_SEC / MSG_BURST 20 / 40 Per-connection message rate for clients (excess dropped, sustained excess disconnects); the links are not limited
TLS_CERT_FILE / TLS_KEY_FILE (empty) Certificate and key; set both or neither. Compose: the world server's dev certificate
TLS_DEV_CERT_DIR ./certs Without the two above: a self-signed dev certificate is made here
AUTH_JWKS_URL (required) The auth service's JWKS, to verify access tokens
JWT_ISSUER / JWT_AUDIENCE kast-auth / kast Required iss / aud
JWT_CLOCK_SKEW_SECONDS 5 Leeway on exp
JWKS_REFRESH_SECONDS / JWKS_MIN_REFETCH_SECONDS / JWKS_TIMEOUT_MS 300 / 10 / 3000 JWKS cache, as the world server's
DB_HOST / DB_PORT (required) / 3306 MySQL for the mutes
DB_USER / DB_PASSWORD / DB_NAME (required) Compose: kast_chat / CHAT_DB_PASSWORD / kast_chat
DB_CONNECT_TIMEOUT_SECONDS 3
MIGRATIONS_DIR ./migrations Applied at startup, once each (schema_migrations, named lock kast_chat_migrate)
CHAT_CHANNELS General,Trade,LFG 1 to 9 names of 1-16 letters or digits; numbered from 1 in this order (/1, /2, ...). Every client is put in the first on connect
CHAT_MAX_BYTES 256 UTF-8 bytes per message (as the world server's say)
CHAT_RATE_COUNT / CHAT_RATE_WINDOW_MS 5 / 10000 Messages per sender per sliding window (whispers, channel and zone lines together)
CHAT_MUTE_MAX_MINUTES 525600 Longer mutes are cut to this (a year)
LOG_LEVEL info debug, info, warn or error
