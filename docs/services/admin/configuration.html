Configuration

All configuration comes from environment variables (.env for the npm scripts; see services/admin/.env.example). They are validated with zod at startup, and the process exits listing every bad or missing variable.

VariableDefaultDescription
PORT3200HTTP port (API and SPA)
TRUST_PROXYfalseExpress trust proxy (true, a hop count, or subnets)
COOKIE_SECUREtrueSession and CSRF cookies are Secure. false only for plain-http development (compose sets it, on localhost)
STATIC_DIRweb/distThe built SPA
AUTH_URLrequiredAuth service base URL (compose: http://auth:3000). Its JWKS verifies access tokens
JWT_ISSUER / JWT_AUDIENCErequiredMust match auth's
DB_HOST / DB_PORTrequired / 3306MySQL holding both databases
ADMIN_DB_USER / ADMIN_DB_PASSWORD / ADMIN_DB_NAMErequiredOwns kast_admin (audit log, realm endpoint copy) only
WORLD_DB_USER / WORLD_DB_PASSWORD / WORLD_DB_NAMErequiredSELECT and UPDATE on kast_world.characters only
WORLD_ADMIN_SECRETrequired, 16+ charactersThe world servers' WORLD_ADMIN_SECRET. Never logged, stored or returned
WORLD_ADMIN_CA_FILEsystem CAsPEM CA for the world servers' TLS certificates (compose: the world dev cert, /certs/server.crt)
WORLD_ADMIN_TIMEOUT_MS3000Connect + reply timeout per admin-port request; past it the realm counts as unreachable
TEST_MYSQL_ROOT_PASSWORD, TEST_ADMIN_DB_NAME, TEST_WORLD_DB_NAME-npm test only

World compose stack

services/world/.env (see its .env.example) adds these for the admin app; the compose file sets the rest (AUTH_URL, DB_HOST, the CA path, COOKIE_SECURE=false).

VariableDefaultDescription
ADMIN_HOST_PORT3200Host port, bound to 127.0.0.1
ADMIN_DB_PASSWORDrequiredPassword of the kast_admin user (ADMIN_DB_USER, default kast_admin)
ADMIN_WORLD_DB_PASSWORDrequiredPassword of the characters-only world user (ADMIN_WORLD_DB_USER, default kast_world_admin)
WORLD_ADMIN_SECRETempty = admin port offShared by the world and the admin service. Empty also keeps the admin service from starting
SEED_ADMIN_EMAIL / SEED_ADMIN_PASSWORDemptyPassed to auth, which creates this pre-verified admin on start if the email is unused (both or neither)

admin-db-init creates users with CREATE USER IF NOT EXISTS: changing a password in .env later does not change an existing user. Use ALTER USER as MySQL root, or a fresh volume.

Realm admin endpoint

Each realm in auth has optional adminHost / adminPort (Realms page): where the admin service reaches that realm's world admin port. A realm without them is unreachable: online list, kick and non-forced character writes answer 503 realm_unreachable.
