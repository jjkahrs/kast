Endpoints

JSON over HTTP under /api, same origin as the SPA. Authentication is by session cookie (see Security behaviour); every non-GET needs the X-CSRF-Token header. Every mutating route writes one audit row. Roles: A = admin, G = gm.

Session

MethodPathRolesDescription
GET/api/sessionA, G{id, email, role}, or 401. Also hands out the CSRF cookie
POST/api/session/loginanyone{email, password} → {id, email, role} and the session cookies; players get 403. Replaces the CSRF cookie
POST/api/session/logoutanyoneLogs out in auth and clears the cookies → 204

POST/api/accounts/:id/unlockA→ 204

Characters

MethodPathRolesDescription
GET/api/charactersA, GQuery realmId, accountId, name (prefix), includeDeleted, limit, offset → {characters, total, limit, offset}
GET/api/characters/:idA, GSummary + position {x, y, z}, heading, components, options
PUT/api/characters/:id/nameA, G{name, force?}: 3-16 ASCII letters, unique per realm including deleted characters (409 name_taken)
PUT/api/characters/:id/positionA, G{mapId, x, y, z, heading, force?}
PUT/api/characters/:id/componentsA, G{components, force?}: a JSON object, ≤64 KiB
PUT/api/characters/:id/optionsA, G{options, force?}: a JSON object, ≤64 KiB
DELETE/api/characters/:idA, GSoft delete; body {force?}
POST/api/characters/:id/restoreA, GClears deleted_at; body {force?}

Every write answers the character after the change and goes through the online guard: online → 409 character_online (details {realmId, accountId}); realm unreachable → 503 realm_unreachable unless an admin sends force: true; a GM's force → 403.

Realms, online, kick

GET/api/realms/:idAOne realm
POST/api/realmsA{name, host, port, adminHost?, adminPort?, region, status?, sortOrder?} → 201
PUT/api/realms/:idASame body
DELETE/api/realms/:idA→ 204
GET/api/realms/:id/onlineA, G{online: [{accountId, characterId, characterName, mapId, sessionId, connectedAt}]}; lobby sessions have characterId 0
GET/api/realms/:id/instancesA, G{instances: [{mapId, mapName, instanceId, key, players, npcs, createdAt, emptySince}]}: the realm's live map contexts (AdminInstancesReq); instanceId 0 for a world map, key '' when keyless, emptySince null unless an empty copy's timer runs. 503 realm_unreachable like online
POST/api/realms/:id/kickA, G{accountId | characterId, reason (1-200)} → {kicked}

Audit

MethodPathRolesDescription
GET/api/auditAQuery actorId, action, targetType, targetId, from, to (ISO 8601), limit, offset → {entries, total, limit, offset}. Entry: id, actorAccountId, actorEmail, actorRole, action, targetType, targetId, before, after, forced, result, createdAt; result is ok or the error code

Also: GET /health → {status, db} (503 db_unavailable). Any other GET outside /api serves the SPA.

Errors

Errors are {"error": {"code", "message", "details"?}}, as in auth. Auth's codes (for example email_taken, account_not_found, invalid_credentials, rate_limited) pass through unchanged.

StatusCodeWhen
