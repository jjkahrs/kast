Kast Documentation

Kast is a C++20 game engine focused on making it easy to build MMORPGs. How to build and start the editor and the services is in the repository README.

Sections

  • Editor: kast_editor, its command line, panels, Project Manager, projects, Build and the GUI Builder.
  • Engine: scene conventions, rendering, physics, audio, networking, game GUIs and the kast.* Lua API.
  • Auth Server: accounts, sessions and the realm list (services/auth).
  • World Server: the MMORPG world server (services/world) and its wire protocol.
  • Development: the test suite and the source layout.

Tools

  • Zone Builder: kast_zone_builder, the zone map editor.
  • Map Bake: kast_mapbake, the world server's navmesh baker.
